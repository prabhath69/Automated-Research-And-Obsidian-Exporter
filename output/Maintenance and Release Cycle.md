- Flutter app maintenance: ongoing expense, ~15–20% of original build cost per year.
- Covers OS updates, security patches, SDK upgrades, bug fixes, performance optimization.
- Regular maintenance (dependency updates, security audits) essential for performance and security.
- Flutter release cycle: stable, beta, main channels; stable releases quarterly; migration guides for breaking changes.

See [[Productivity and Cost]], [[Security Considerations]].
