---
title: Platform Support and Code Reuse
tags: [flutter, react-native, platforms, code-reuse]
date: 2026-08-28
---

- **Flutter:**
    - Broad first-party support: mobile, web, desktop (Windows, macOS, Linux), embedded.
    - High code reuse (90–95%).
- **React Native:**
    - Primarily mobile; web/desktop via community projects.
    - Code reuse typically 70–85%, more platform-specific adjustments needed.
