## Flutter
- Out-of-the-box accessibility: semantic annotations, dynamic font scaling, screen reader support, focus navigation.
- Automatic accessibility trees, opt-in semantics for web, custom widgets via Semantics class.
- Supports WCAG standards (touch targets, focus, assistive tech).

## React Native
- Accessible props, AccessibilityInfo API, keyboard navigation, custom actions.
- Some Android accessibility issues (Expo) have been fixed.
- Supports WCAG standards.
